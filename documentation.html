Calculator Features

The calculator includes the following essential features for tracking calculations:

Record

What it does: Saves the current expression and result into the history stack.

How it functions:
  • When you press the "Record" button, the current expression is evaluated.
  • Both the expression and result are stored in the history array.
  • A timestamp is added to show when the calculation was recorded.
  • The history list updates immediately.
Purpose: Keep a permanent log of all calculations for later review.
Example: 12 + 34 = 46 → Click "Record" → Saved to history

Preview

What it does: Displays the last recorded calculation on the screen without saving it again.

How it functions:
  • When you press the "Preview" button, the most recent history entry is retrieved.
  • The expression appears in the display area.
  • The result appears in the result area.
  • Nothing is saved to history (no duplication).
Purpose: Quickly check previous calculations without adding duplicates to history.
Example: Click "Preview" → Shows "12 + 34 = 46" on screen

Retrieve (Redrive)

What it does: Restores a previous calculation from history back into the active display.

How it functions:
  • When you press the "Retrieve" button, the last entry is removed from history.
  • The expression is placed in the display area.
  • The result appears in the result area.
  • The entry is permanently removed from history.
Purpose: Reuse past calculations or correct errors by retrieving them for editing.
Example: Click "Retrieve" → Brings back "12 + 34 = 46" for editing

Clear History

What it does: Permanently deletes all saved entries from the history stack.

How it functions:
  • When you press the "Clear History" button, a confirmation dialog appears.
  • If confirmed, the history array is completely emptied.
  • The history list shows "No calculations recorded".
  • A confirmation message appears: "✅ History cleared!"
Purpose: Reset the log for privacy or a fresh start with a clean history.
Example: Click "Clear History" → All entries removed → "History cleared!"

Delete (Single Entry)

What it does: Removes one specific entry from the history list.

How it functions:
  • Each history entry has a small X (delete) button.
  • When clicked, that specific entry is removed.
  • Other entries remain untouched.
  • The history list updates immediately.
Purpose: Remove unwanted or incorrect calculations individually without affecting others.
Example: Click X on "12 + 34 = 46" → Only that entry is removed

Delete (Character)

What it does: Removes one character at a time from the current expression.

How it functions:
  • When you press the "Del" button, the last character is removed.
  • Each press removes one character.
  • The display updates immediately.
  • History is not affected.
Purpose: Fix typing mistakes one character at a time without clearing everything.
Example: "123+" → Press Del → "123"

Clear (Display)

What it does: Clears the entire current expression at once.

How it functions:
  • When you press the "C" (Clear) button, the entire expression is removed.
  • The display shows "0".
  • History is not affected.
Purpose: Quickly start a new calculation from scratch.
Example: "123+456" → Press C → "0"

Algorithm

Data Structure

history = [
    {
        expression: "12 + 34",
        result: 46,
        timestamp: "2026-08-06 14:32:00"
    }
]

Core Functions

  • Record: history.push({ expression, result, timestamp })
  • Preview: last = history[history.length - 1]
  • Retrieve: last = history.pop()
  • Clear History: history = []
  • Delete (char): expression.slice(0, -1)
  • Clear Display: expression = ""
