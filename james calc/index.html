1. Modulus & Exponentiation

Development and Improvement of a Scientific Calculator

The task was to develop and improve a calculator using HTML, CSS and JavaScript. The calculator performs basic arithmetic operations as well as modulus and exponent calculations.

2. Algorithm

The following steps describe the process used to solve the calculator task:

  1. The user enter two numbers and select either the MOD or EXP button.
  2. The calculator stores the expression entered by the user.
  3. When the = button is clicked, the calculate() function is executed.
  4. The program checks whether the expression contains MOD.
  5. if MOD is found, the expression is split into two numbers using the Number() function.
  6. The two values are converted from text into number using the Number() function.
  7. The program checks whether the section number is zero. if is zero, it displays "Error" because modulus by zero is not allow.
  8. if the second number is not zero, the program calculates the remainder using the MOD operator and displays the answer on the calculator screen.
  9. if the expression does not contain MOD, the program checks whether it conatins the exponents symbol ^.
  10. if the ^ symbol is not found, the expression is split into two numbers.
  11. The two values are converted into numbers using the Number() function.
  12. The variable result is initialized to 1.
  13. A for loop multiplies the base by itself repeatedly according to the exponent entered by the user.
  14. After the loop finishes, the final result is displayed on the calculator screen.

4. Detailed Code Explanation

HTML

HTML was used to create the structure of the calculator. It contains the calculator container, buttons, input screen and operators.

  • DOCTYPE html: Defines the document as an HTML5 document.
  • html: Contains the entire webpage.
  • head: Contains information about the webpage.
  • meta charset: Allows the webpage to correctly display characters.
  • meta viewport: Makes the webpage responsive.
  • link: Connects the HTML file to the CSS stylesheet.
  • body: Contains everything displayed on the webpage.
  • button: Creates buttons that users can click.
  • input: Creates the calculator display screen.

CSS

CSS was used to improve the appearance and layout of the calculator.

  • The calculator background was given a dark color.
  • Buttons were given rounded shapes.
  • Different colors were used to distinguish operators from number buttons.
  • CSS Grid was used to arrange the calculator buttons.
  • Padding and gaps were used to prevent buttons from touching each other.
  • Hover and active effects were added to make the calculator interactive.

JavaScript

JavaScript provides the functionality of the calculator. It receives the values from the buttons and performs the calculations.

  • getElementById() is used to access the calculator screen.
  • appendtodisplay() adds numbers and operators to the display.
  • clearDisplay() clears the calculator screen.
  • calculate() determines which mathematical operation the user wants to perform.
  • split() separates the two numbers in an expression.
  • Number() converts text values into numbers.
  • The modulus operator calculates the remainder.
  • A for loop is used to calculate exponents without Math.pow().
