MATHEMATICS CALCULATOR PROJECT

Combination and Simultaneous Equations

A calculator for combinations and simultaneous equations.

Details of the Work

This work is a calculator built with HTML, CSS, and JavaScript. It performs normal mathematical calculations and also solves combinations and simultaneous equations.

Combination

definition

Combination refers to the way of choosing numbers where others does not matter.

The calculator calculates combinations using the nCr button. For example, 5C2 = 10.

nCr = n! / [r! × (n − r)!]

Simultaneous Equations

Definition

simultaneous equation refer two or more equations hat that uses the same unknown value usualy x and y.
You solve them together to find the value that makes the equation true.

The calculator finds the values of x and y from two equations.

a₁x + b₁y = c₁
a₂x + b₂y = c₂

Algorithm

Definition

Refers to the step by step process use to solve a problem.

Combination Algorithm

  1. Read the values before and after C.
  2. Check whether n and r are valid.
  3. Apply the nCr formula.
  4. Display the answer on the calculator screen.

Simultaneous Equation Algorithm

  1. Read a₁, b₁, c₁, a₂, b₂, and c₂.
  2. Calculate: det = a₁b₂ − a₂b₁.
  3. If det is 0, show no solution or infinite solutions.
  4. Otherwise calculate x and y using Cramer’s rule.

Conception

Definition

Concetion refers to the procedue taken to complete a task.

HTML creates the calculator display, buttons, and equation form. CSS Grid arranges the buttons into rows and columns. JavaScript performs the calculations with functions such as combinationNum() and solveSimultaneous().

The calculator uses a dark background and a light screen so that the calculation and answer are easy to read.
